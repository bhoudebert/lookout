# Support

- **Something broken**: open a bug report with the issue template. Include the output of `lookout doctor`.
- **An idea**: open a feature request, or check `ROADMAP.md` first; it may be listed.
- **A question on usage**: GitHub Discussions if enabled, otherwise an issue with the `question` label.
- **A security concern**: see `SECURITY.md`; do not open a public issue.

This is a personal open-source project maintained on spare time. Answers can take a few days.
